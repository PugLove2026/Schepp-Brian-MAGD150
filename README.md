# Schepp-Brian-MAGD150
Repo for MAGD150 course

Lab 1 is a grayscale image of a cityscape
Lab 6 is an image of a snowman with animated snowfall
Lab 7 is multiple lists based on the parent array, it seperates the characters into two teams of five at random (one character from the parent will always be unused). The characters of each team are written out, in the first two rows, then the next two rows are one random character from each team, finally the fifth row is random character from both of the teams combined
